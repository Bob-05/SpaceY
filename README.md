# 🚀 SpaceY — Космический агрегатор

> ⚠️ **Важно:** Данный проект является **учебным** и создан в рамках практической работы по веб-программированию. Все бренды, названия и цены являются вымышленными и не имеют отношения к реальным компаниям или услугам.

Современный лендинг для коммерческих космических путешествий. Проект выполнен в футуристическом стиле с тёмной темой, неоновыми акцентами и адаптивным дизайном.

**Демо:** [bob-05.github.io/SpaceY](https://bob-05.github.io/SpaceY/)

**Репозиторий:** [github.com/Bob-05/SpaceY](https://github.com/Bob-05/SpaceY)

## 📋 О проекте

SpaceY — это концептуальный сайт-агрегатор для бронирования коммерческих космических туров. Проект разработан в рамках учебной практики по веб-программированию и демонстрирует навыки создания адаптивных интерфейсов с использованием современных технологий.

### Ключевые страницы:

| Страница | Описание |
|----------|----------|
| **Главная** | Hero-блок, статистика, телеметрия, популярные маршруты, преимущества |
| **Билеты** | Выбор маршрута с радио-кнопками и расчёт стоимости |
| **Отзывы** | Просмотр отзывов и форма для добавления нового |
| **Поддержка** | Форма обратной связи с валидацией полей |

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| **HTML5** | Семантическая разметка |
| **CSS3** | Стилизация, анимации, адаптивность |
| **Flexbox** | Гибкое позиционирование элементов |
| **CSS Grid** | Сетка карточек и преимуществ |
| **БЭМ** | Методология именования классов |
| **Google Fonts** | Шрифты *Space Grotesk* и *Inter* |

## 🎨 Особенности дизайна

### Цветовая палитра

| Цвет | Код | Назначение |
|------|-----|------------|
| Фон | `#0b0c0e` | Основной тёмный фон |
| Акцент | `#00b4ff` | Кнопки, ссылки, акценты |
| Ошибка | `#ff3b5c` | Буква "Y" в логотипе, акценты |
| Успех | `#00d4aa` | Статусы, цены, индикаторы |

### Шрифты

| Шрифт | Назначение |
|-------|------------|
| **Space Grotesk** | Заголовки (технологичный, с увеличенным межбуквенным интервалом) |
| **Inter** | Основной текст (чистый, читаемый) |

## 📱 Адаптивность

| Устройство | Ширина экрана | Особенности |
|------------|---------------|-------------|
| Десктоп | > 1024px | Полноценная сетка 4+ колонок |
| Планшет | 768px - 1024px | Сетка 2-3 колонки, герой в столбец |
| Мобильный | < 768px | Одна колонка, кнопки на всю ширину |

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Bob-05/SpaceY.git
```

### 2. Открыть в браузере

Просто откройте index.html в любом браузере.
